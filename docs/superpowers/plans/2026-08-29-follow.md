# Follow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Seguir/deixar de seguir persistido no Supabase, com contagem real de seguidores/seguindo, substituindo o botão local fake do `UserProfileView`.

**Architecture:** Tabela `follows` (par follower/following) com RLS de leitura pública, insert/delete só pelo próprio `follower_id`. `SupabaseService` ganha 4 métodos. `UserProfileView` e `ProfileView` passam a mostrar estado/contagem real.

**Tech Stack:** SwiftUI, supabase-swift, Supabase Postgres + RLS.

**Spec:** `docs/superpowers/specs/2026-08-29-follow-design.md`

## Global Constraints

- Sem lista navegável de seguidores/seguindo, sem notificação de novo seguidor, sem sugestões (spec: Fora de escopo)
- RLS: leitura pública, insert/delete só pelo próprio `follower_id` (spec: Dados)
- `no_self_follow` protege contra seguir a si mesmo

### Task 2: `SupabaseService` — 4 métodos de Follow

**Files:**
- Modify: `Spot It/Spot It/Services/SupabaseService.swift`

**Interfaces:**
- Produces:
  - `static func follow(userId: UUID) async throws`
  - `static func unfollow(userId: UUID) async throws`
  - `static func isFollowing(userId: UUID) async throws -> Bool`
  - `static func followCounts(userId: UUID) async throws -> (followers: Int, following: Int)`

- [ ] **Step 1: Adicionar os 4 métodos**, todos chamando `try ensureSignedIn()` primeiro:

```swift
    static func follow(userId: UUID) async throws {
        try ensureSignedIn()
        guard let myId = client.auth.currentSession?.user.id else { throw SupabaseError.notSignedIn }
        struct NewFollow: Encodable {
            let follower_id: UUID
            let following_id: UUID
        }
        try await client.from("follows")
            .insert(NewFollow(follower_id: myId, following_id: userId))
            .execute()
    }

    static func unfollow(userId: UUID) async throws {
        try ensureSignedIn()
        guard let myId = client.auth.currentSession?.user.id else { throw SupabaseError.notSignedIn }
        try await client.from("follows")
            .delete()
            .eq("follower_id", value: myId)
            .eq("following_id", value: userId)
            .execute()
    }

    static func isFollowing(userId: UUID) async throws -> Bool {
        try ensureSignedIn()
        guard let myId = client.auth.currentSession?.user.id else { throw SupabaseError.notSignedIn }
        struct FollowRow: Decodable { let follower_id: UUID }
        let rows: [FollowRow] = try await client.from("follows")
            .select("follower_id")
            .eq("follower_id", value: myId)
            .eq("following_id", value: userId)
            .limit(1)
            .execute()
            .value
        return !rows.isEmpty
    }

    static func followCounts(userId: UUID) async throws -> (followers: Int, following: Int) {
        try ensureSignedIn()
        struct IdRow: Decodable { let follower_id: UUID }
        struct IdRow2: Decodable { let following_id: UUID }
        let followers: [IdRow] = try await client.from("follows")
            .select("follower_id")
            .eq("following_id", value: userId)
            .execute()
            .value
        let following: [IdRow2] = try await client.from("follows")
            .select("following_id")
            .eq("follower_id", value: userId)
            .execute()
            .value
        return (followers.count, following.count)
    }
```

Nota pro implementador: se o supabase-swift instalado tiver uma forma mais direta de contar linhas (ex: `.select(..., head: true, count: .exact)` retornando a contagem sem baixar todas as linhas), prefira essa — mais eficiente que baixar tudo só pra contar. Confirme a API real do SDK antes de escolher; o comportamento importa mais que a sintaxe exata (retornar quantos seguidores e quantos seguindo aquele `userId` tem).

        do {
            if isFollowing {
                try await SupabaseService.unfollow(userId: userId)
                isFollowing = false
                followersCount -= 1
            } else {
                try await SupabaseService.follow(userId: userId)
                isFollowing = true
                followersCount += 1
            }
        } catch {
            errorMessage = error.localizedDescription
        }
    }
